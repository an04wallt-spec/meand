# Мысли

Личный журнал и Android-приложение для публикации записей в `blog.html` сайта meand.ru.

В приложении заметки собраны в ленту, а дата и время создания сохраняются автоматически. Эти данные остаются только в приложении и никогда не передаются в публичный блог.

## Использование

1. При первом запуске открыть настройки.
2. Ввести fine-grained GitHub token с доступом только к репозиторию `an04wallt-spec/meand` и разрешением `Contents: Read and write`.
3. Создать заметку: заголовок, текст и время сохраняются автоматически.
4. Нажать «Опубликовать», когда запись готова.

Черновик сохраняется автоматически. GitHub token хранится в зашифрованном виде с ключом Android Keystore.
